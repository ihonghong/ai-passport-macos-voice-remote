# v0.1.1 — AI Passport Mac Voice Remote (Unsigned Beta)

This patch release fixes a macOS Bridge state-recovery issue. Existing v0.1.0
devices do not need a firmware update; replace only the macOS App.

## Fixed

- Retries a failed BLE HID Output Report up to three times before giving up.
- Keeps the connected audio and input path active when one periodic status
  update cannot be delivered, instead of latching the Bridge into an offline
  error state and restoring the physical microphone.
- Adds host regression coverage for both transient recovery and the bounded
  persistent-failure path.

## Upgrade

1. Quit the existing `AI Passport.app`.
2. Replace it with the App from `AI-Passport-macOS.zip` and open it again.
3. If macOS rejects HID access after replacement, toggle `AI Passport` off and
   on under **System Settings > Privacy & Security > Input Monitoring**, then
   reopen the App.

The release also includes `FoloToy-AI-Passport-full.bin` for new installations,
plus `SHA256SUMS.txt` for both downloadable binaries. The App remains an
ad-hoc-signed, non-notarized Unsigned Beta.

## Verification

The release gate runs repository and host regression tests, universal macOS App
compilation, an ESP-IDF 5.5.3 firmware build, merged-image validation, and the
protected `cardid`/Recovery exclusion checks.
