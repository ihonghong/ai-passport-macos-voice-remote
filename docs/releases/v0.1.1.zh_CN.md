# v0.1.1 — AI Passport Mac 语音遥控器（Unsigned Beta）

这个补丁版本修复 macOS Bridge 的状态恢复问题。已经使用 v0.1.0 的设备不需要更新
固件，只需替换 macOS App。

## 修复

- BLE HID Output Report 写入失败后最多重试 3 次。
- 单次周期状态下发失败时继续保持已连接的音频与输入路径，不再把 Bridge 永久锁在
  离线错误状态并切回物理麦克风。
- 增加主机回归测试，覆盖瞬时错误恢复和持续失败时的重试上限。

## 升级

1. 退出当前的 `AI Passport.app`。
2. 使用 `AI-Passport-macOS.zip` 中的新 App 替换旧版本并重新打开。
3. 如果替换后 macOS 拒绝 HID 访问，请在**系统设置 > 隐私与安全性 > 输入监控**中
   关闭再打开 `AI Passport`，然后重新启动 App。

Release 同时包含供全新安装使用的 `FoloToy-AI-Passport-full.bin`，以及两个下载文件的
`SHA256SUMS.txt`。App 仍然是使用临时签名、未经 Apple 公证的 Unsigned Beta。

## 验证

Release 门禁会运行仓库和主机回归测试、通用 macOS App 编译、ESP-IDF 5.5.3 固件
构建、合并镜像校验，以及受保护 `cardid`／Recovery 排除检查。
