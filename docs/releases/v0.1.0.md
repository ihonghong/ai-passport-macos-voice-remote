# v0.1.0 — AI Passport Mac Voice Remote

This is the first public release of the AI Passport Mac Voice Remote. It turns
the ESP32-C3 card into one encrypted BLE HID device that provides physical
shortcuts, push-to-talk microphone streaming, and a compact status display for
macOS.

## What's new

- Streams the card microphone wirelessly to a native macOS menu-bar App and
  exposes it through `BlackHole 2ch` to dictation or input-method software.
- Maps the physical Up, Mid, and Down controls directly. Public defaults are
  Command-Delete, Return, and Left Control + Left Command respectively.
- Shows date, weekday, time, battery, connection state, optional usage metrics,
  and the stable Ready or Listening state on the card display.
- Includes random six-digit BLE pairing codes, encrypted bonding, automatic
  reconnection, conservative idle connection parameters, and display deep-idle
  behavior.
- Embeds the former Python Bridge functionality in one universal native App;
  Python is not a runtime dependency.

## Release assets

- `FoloToy-AI-Passport-full.bin`: verified ESP32-C3 merged firmware for the
  permanent Recovery installer.
- `AI-Passport-macOS.zip`: Developer ID signed and notarized universal App for
  Apple silicon and Intel Macs.
- `SHA256SUMS.txt`: SHA-256 digests for both downloadable binaries.

The public firmware uses generic metric labels and contains no private pet
artwork, device identity, Bluetooth bond, or personal configuration.

## Requirements

- A factory-provisioned FoloToy AI Passport with its permanent Recovery intact.
- macOS 13 or later.
- `BlackHole 2ch`, installed once as the system virtual-audio component.
- A dictation application or input method whose global voice shortcut can be
  configured to match the card's Down-button mapping.

## Install

1. Hold Up while powering on the card for five seconds, enter permanent
   Recovery, and install `FoloToy-AI-Passport-full.bin` with the official
   mini-program.
2. Install `BlackHole 2ch` and restart macOS if its installer requests it.
3. Unzip `AI-Passport-macOS.zip`, move `AI Passport.app` to Applications, open
   it, and grant Input Monitoring access when macOS asks.
4. Pair `AI Passport` in System Settings > Bluetooth. Enter the six-digit code
   displayed on the card when creating a new bond.
5. Bind the chosen dictation or input method to Left Control + Left Command, or
   edit the Down mapping in the App configuration to match another shortcut.

Do not raw-write the merged firmware at `0x0` for a normal update. That path
clears runtime NVS and the Bluetooth bond. Use permanent Recovery for normal
installation and segmented `idf.py flash` for development.

## Configuration

The native App stores configuration at
`~/Library/Application Support/AI Passport Bridge/config.json`. Saving the file
does not change the running bridge. Choose **Apply latest configuration (restart
audio bridge)** from the menu-bar App to reload it and send the latest button
map to the card.

Metrics are off by default. Set the Provider to `auto` or `codex` to show local
Codex quota and daily-token data. Those local session records are not uploaded.

## Known limitations

- `BlackHole 2ch` remains a separate system audio component and requires a
  one-time installation.
- The wireless microphone stream is 8 kHz mono, optimized for speech rather
  than music recording.
- New pet artwork remains a compile-time firmware plugin; it cannot be uploaded
  from the macOS configuration file.
- Users must configure their own dictation or input-method shortcut. The App
  does not modify third-party input-method settings.

## Verification

The release gate runs repository checks, host protocol tests, native Swift
type-checking, an ESP-IDF 5.5.3 build, merged-image offset verification, the
3 MB application limit, and protected `cardid`/Recovery exclusion. After
publication, the downloaded firmware still requires a final installation and
shortcut/audio check on real hardware.
