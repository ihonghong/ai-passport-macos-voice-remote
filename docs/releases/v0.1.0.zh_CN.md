# v0.1.0 — AI Passport Mac 语音遥控器

这是 AI Passport Mac 语音遥控器的第一个公开版本。它把 ESP32-C3 卡片变成一个加密的
BLE HID 设备，同时为 macOS 提供实体快捷键、按住说话的麦克风流和紧凑状态屏幕。

## 新功能

- 通过无线方式把卡片麦克风传输到原生 macOS 菜单栏 App，再经 `BlackHole 2ch`
  提供给听写或输入法软件。
- 直接映射实体上、中、下三个按键。公开默认值依次为 Command-Delete、Return 和
  左 Control + 左 Command。
- 屏幕显示日期、星期、时间、电量、连接状态、可选用量指标，以及稳定的 Ready 或
  Listening 状态。
- 支持随机 6 位 BLE 配对码、加密绑定、自动重连、保守的空闲连接参数和屏幕深度
  空闲策略。
- 原来的 Python Bridge 能力已经进入一个通用原生 App；运行时不再依赖 Python。

## Release 产物

- `FoloToy-AI-Passport-full.bin`：通过验证、供永久 Recovery 安装器使用的 ESP32-C3
  合并固件。
- `AI-Passport-macOS.zip`：经过 Developer ID 签名与 Apple 公证，同时支持 Apple
  芯片和 Intel Mac 的通用 App。
- `SHA256SUMS.txt`：两个可下载二进制文件的 SHA-256 校验值。

公开固件使用通用指标文案，不包含私人宠物素材、设备身份、蓝牙绑定或个人配置。

## 使用要求

- 保留出厂永久 Recovery 的 FoloToy AI Passport。
- macOS 13 或更高版本。
- 只需安装一次的系统虚拟音频组件 `BlackHole 2ch`。
- 支持配置全局语音快捷键的听写应用或输入法，并将其设为与卡片下键映射一致。

## 安装

1. 卡片上电时按住上键 5 秒进入永久 Recovery，再通过官方小程序安装
   `FoloToy-AI-Passport-full.bin`。
2. 安装 `BlackHole 2ch`；如果安装器要求重启，请重启 macOS。
3. 解压 `AI-Passport-macOS.zip`，把 `AI Passport.app` 移入“应用程序”，打开它，
   并在 macOS 提示时授予输入监控权限。
4. 在“系统设置 > 蓝牙”中配对 `AI Passport`。建立新绑定时，输入卡片屏幕显示的
   6 位数字。
5. 把所选听写应用或输入法绑定为左 Control + 左 Command；也可以修改 App 配置中的
   下键映射，使其匹配其他快捷键。

不要把从 `0x0` 裸写合并固件作为普通升级方式。该路径会清除运行 NVS 和蓝牙绑定。
普通安装使用永久 Recovery，开发过程使用分段 `idf.py flash`。

## 配置

原生 App 的配置位于
`~/Library/Application Support/AI Passport Bridge/config.json`。只保存文件不会改变
当前运行的 Bridge；请从菜单栏 App 选择“应用最新配置（重启音频桥）”，重新加载文件
并把最新按键映射发送给卡片。

指标默认关闭。把 Provider 设为 `auto` 或 `codex` 后，可以显示本机 Codex 剩余额度和
每日 Token 数据；本机会话记录不会被上传。

## 已知限制

- `BlackHole 2ch` 仍是独立的系统音频组件，需要一次性安装。
- 无线麦克风为 8 kHz 单声道，针对语音而不是音乐录制优化。
- 新宠物素材仍是编译期固件插件，无法从 macOS 配置文件上传。
- 用户必须自行配置听写应用或输入法快捷键；App 不会修改第三方输入法设置。

## 验证
